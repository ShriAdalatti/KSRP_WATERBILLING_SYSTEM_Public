# 💧 Water Billing Management System

A full-stack **Water Billing Management System** developed using **Node.js, Express.js, MongoDB, EJS, HTML, CSS, and JavaScript** to digitize residential water billing and streamline administrative operations through a secure, user-friendly web application.

## 📖 Overview

This project was developed based on the operational requirements of the **3rd Battalion, Karnataka State Reserve Police (KSRP) Residential Quarters**. It replaces manual billing processes with a digital system that enables administrators to manage residents, generate and monitor water bills, and track payment status, while allowing residents to securely access their billing information online.

## 💡 Inspiration

During a visit to the **3rd Battalion, Karnataka State Reserve Police (KSRP) Bengaluru** with my brother, I observed that the water billing process relied heavily on manual record-keeping. This inspired me to build a digital solution demonstrating how modern web technologies can simplify residential utility management.

## ✨ Key Features

### 👨‍💼 Administrator Portal

* Secure Administrator Authentication
* Dashboard with Billing Statistics
* Resident Management (Add, Update & Delete)
* Excel-based Monthly Bill Upload
* Water Bill Management
* Reports & Payment Tracking

### 👤 Resident Portal

* Secure User Login
* View Monthly Water Bills
* Payment Status Tracking
* Help & Support Portal

## 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, JavaScript, EJS

**Backend:** Node.js, Express.js

**Database:** MongoDB, Mongoose

**Libraries:** Express Session, bcrypt, Multer, XLSX, QRCode, dotenv

## 🚀 Installation

```bash
git clone https://github.com/ShriAdalatti/KSRP_WATERBILLING_SYSTEM_Public.git

cd KSRP_WATERBILLING_SYSTEM_Public

npm install
```

Create a `.env` file:

```env
SESSION_SECRET=YourSecretKey
```

Run the application:

```bash
npm start
```

or

```bash
nodemon server.js
```

Visit:

```
http://localhost:3000
```

## 🔒 Portfolio Version Notice

This repository contains the **public portfolio version** of the original project.

The original application was developed for the **3rd Battalion, Karnataka State Reserve Police (KSRP) Bengaluru**. To make the project suitable for public sharing, official logos, organization-specific branding, and sensitive configuration files have been removed or replaced with generic assets.

The **core architecture, authentication system, database design, administrative modules, and billing workflow remain the same as the original implementation**. These modifications were made solely to ensure that the repository can be safely shared for educational and portfolio purposes without implying any official association with KSRP.
